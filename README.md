# 2.5scroller

A polished 2.5D side-scrolling adventure game built in Godot.

The game stars a stylised owl inspired by the Apps4Owls character
and is intended to combine responsive platforming and gliding with
high-quality atmospheric 3D environments.

## Primary Target

- Godot 4.x
- Desktop web browser
- 1920x1080
- Keyboard-first controls
- 60 FPS target
- High visual quality
- 3D environments with constrained 2.5D gameplay

## Development

This project is being developed with assistance from multiple AI models.

All AI contributors must read `AGENTS.md` and the relevant files in
`docs/` before modifying the project.
